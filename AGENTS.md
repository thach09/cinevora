# AGENTS.md — Cinevora

Quy tắc bắt buộc đọc trước khi thực hiện bất kỳ task nào trong repo này.

## Bối cảnh dự án

Chuyển đổi ứng dụng CLI Java thuần (quản lý phim streaming kiểu Netflix, đầy
đủ OOP + thuật toán tự cài: Bubble Sort, Linear Search, Custom Stack) thành
Full-Stack Web Application để làm portfolio cá nhân.

## Tech stack đã chốt — không tự đổi

Backend: Spring Boot 3.x, Java 21 LTS, Spring Data JPA + Hibernate, Spring
Security + JWT, Flyway. Database: PostgreSQL 16. Frontend: React 18 + Vite +
TypeScript, TanStack Query, Zustand, TailwindCSS. DevOps: Docker Compose,
GitHub Actions, deploy Backend/DB lên Render/Railway, Frontend lên Vercel.

Nếu một quyết định kỹ thuật không khớp danh sách trên, dừng lại và hỏi thay
vì tự chọn công nghệ khác.

## Cấu trúc repo

- `legacy-cli/` — code CLI gốc, chỉ để tham khảo logic nghiệp vụ, không sửa,
  không deploy.
- `backend/` — Spring Boot project.
- `frontend/` — React project (chưa khởi tạo).
- `docs/roadmap/` — 7 file kế hoạch theo Phase (00_OVERVIEW →
  06_SECURITY_AND_API_STANDARDS). Đây là nguồn quyết định kiến trúc duy nhất —
  đọc file Phase tương ứng trước khi làm, không tự suy diễn.
- `docs/erd/`, `docs/database/` — ERD, seed mapping, migration runbook.
- `tools/` — script hỗ trợ (hash password, sinh seed SQL), chạy độc lập bằng
  JDK thuần, không phụ thuộc `backend/`.

## Nguyên tắc tái sử dụng code

Business logic trong `legacy-cli/src/controller/` là bất biến — khi chuyển
sang `backend/`, chỉ đổi tên thành `*Service` và đổi cách gọi persistence
sang Spring Data JPA, không viết lại rule nghiệp vụ đã có (ví dụ: không cho
xóa Category còn Movie active tham chiếu). `legacy-cli/src/model/` giữ gần
như nguyên vẹn, chỉ thêm annotation JPA.

## Quyết định đã khóa (không mở lại trừ khi có lý do mới)

- ID: `BIGINT GENERATED BY DEFAULT AS IDENTITY`, không giữ mã nghiệp vụ cũ
  (CAT01/M01) làm khóa chính hay cột riêng.
- Mật khẩu seed: hash BCrypt bằng tool JDK thuần trong `tools/`, không cần
  Maven/backend ở Phase 1. Dữ liệu plaintext gốc đã bị xóa khỏi working tree.
- API: prefix `/api/v1/...`. Response bọc trong `ApiResponse<T>` thống nhất
  cho cả success/error. Pagination dùng `PageResponse<T>` lồng bên trong.
- CORS: đọc allowed-origins từ biến môi trường, không hardcode domain.
- Spring Profiles tách Dev/Prod qua `SPRING_PROFILES_ACTIVE`.

## Quy tắc làm việc bắt buộc

1. Quyết định ảnh hưởng schema hoặc API contract lâu dài: hỏi xác nhận trước
   khi thực thi, không tự quyết rồi báo cáo sau.
2. Báo cáo hoàn thành task phải kèm log/output thực tế đã chạy. Bảng
   checklist ✅ không kèm bằng chứng thực thi thô không được tính là hoàn
   thành.
3. Không mở rộng phạm vi sang Phase khác khi đang làm dở Phase hiện tại.
4. Trả lời/báo cáo súc tích, đúng trọng tâm, không lặp lại cùng một ý nhiều
   lần, không dán nguyên khối code vào báo cáo tóm tắt — mô tả bằng lời, chỉ
   trích dẫn phần code thật sự cần thiết để ra quyết định.
